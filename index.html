Check the server from PowerShell

curl.exe -I http://localhost:8000

Asks the server for the home page's headers only, not the page itself. It's a quick way to see if the server is up.

  • -I sends a HEAD request, meaning "headers only."
  • HTTP/1.0 200 OK in the reply means the server is running.
  • "Failed to connect" means the server is off. Double-click scripts/start-server.bat to start it.
  • X-Server-Id changes each time the server restarts.
  • Type curl.exe, not just curl. In older Windows PowerShell, curl is a shortcut for a different command that doesn't accept -I.

This site runs at http://localhost:8000/. If the page doesn't load, double-click scripts/start-server.bat in the project folder, or ask Claude to restart the server.
